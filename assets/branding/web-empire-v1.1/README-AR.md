- لا تستخدم صورة شاشة كاملة كواجهة تطبيق.
- الأصول مخصصة للشعار والزخرفة فقط.
- الأزرار والبطاقات والنصوص وحقول الإدخال تُبنى بالكود.
- حافظ على مساحة الأمان الموجودة داخل الملفات ولا تقص الحواف مرة أخرى.
