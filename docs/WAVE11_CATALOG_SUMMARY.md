Quality controls used for this wave:

- Proposed slugs were checked against the currently applied production catalog.
- Existing staged Wave 6 and Wave 7 tools were reviewed to avoid simply renaming the same metric.
- Several initially proposed duplicate concepts were replaced with genuinely different calculations before staging.
- Formulas use only arithmetic supported by the current formula engine (`+ - * / % ^` and parentheses).
- Arabic and English tool titles and field labels are included.
- Tools are free, require no authentication, and use no AI provider or external API.
